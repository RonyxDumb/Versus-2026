# Versus 2026
Ricreazione della modalità "_***Mario VS Luigi***_" proveniente dal gioco "_***New Super Mario Bros. DS***_" nel linguaggio Haxe.

### Aggiunte e differenze
- Implementato un sistema di lettura del controller.
- Selezione di più skin del personaggio (membri del mio ex-gruppo).
- Primo stato di implementazione per l'esportazione ***Android***.

### Stato attuale
Lo sviluppo del progetto risulta attualmente sospeso o terminato come incompleto, ma ciò non vuol dire che non possa
essere recuperato in futuro.
